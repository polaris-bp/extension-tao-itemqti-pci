## 1. 目的

本文書は、Math Entry Interaction PCI（Portable Custom Interaction）の概要設計を定義するものである。このPCIは、テスト受験者が数式を入力するためのインタラクションを提供する。

## 2. システム概要

### 2.1 PCIの役割

Math Entry Interactionは、IMS QTI（Question and Test Interoperability）標準に準拠したカスタムインタラクションであり、以下の機能を提供する：

- 数式入力エディタの提供（MathQuillベース）
- LaTeX形式での数式の編集と表示
- ツールバーによる数式記号・関数の入力支援
- Gap Expression モード（穴埋め形式の数式問題）のサポート
- 複数の正解パターンの定義
- スコアリング機能

### 2.2 技術スタック

| 技術 | 用途 |
|------|------|
| MathQuill | 数式エディタのコアライブラリ |
| mathml-to-latex | MathML からLaTeXへの変換 |
| jQuery | DOM操作 |
| Lodash | ユーティリティ関数 |
| Handlebars | テンプレートエンジン |

### 2.3 ライセンス

GPL-2.0-only

## 3. 主要機能

### 3.1 Runtime モード（受験者向け）

受験者が実際にテストを受ける際に使用されるモード。

**機能一覧：**
- 数式入力フィールドの表示
- ツールバーからの数式記号入力
- キーボードによる直接入力
- Gap Expression形式での回答入力
- レスポンスの保存・復元

### 3.2 Creator モード（問題作成者向け）

問題作成者がアイテムを編集する際に使用されるモード。

**機能一覧：**
- 問題プロパティの設定
- ツールバーのカスタマイズ
- Gap Expressionの作成
- 正解の定義（複数の代替回答を含む）
- スコアリング設定

### 3.3 Gap Expression モード

数式の一部を穴埋め形式にする特殊なモード。

**特徴：**
- 数式テンプレート内に編集可能なギャップフィールドを配置
- ギャップのサイズ調整（小・中・大）
- 各ギャップに対する個別の入力制御

```
mathEntryInteraction/

│   ├── mathEntryInteraction.js # メインランタイムモジュール

│   ├── mathml-to-latex/        # MathML変換ライブラリ
│   ├── helper/                 # ヘルパーモジュール
│   └── css/                    # スタイルシート
├── creator/                    # Creator実行時のモジュール

│   │   ├── Widget.js           # メインウィジェット
│   │   └── states/             # 状態管理
│   └── tpl/                    # テンプレート
├── docs/                       # ドキュメント
│   └── design/                 # 設計書
```

### 4.2 主要コンポーネント

## 5. データフロー概要

### 5.1 受験者の回答フロー

```
受験者入力
  ↓
MathQuillエディタ
  ↓
LaTeX形式に変換
  ↓
曖昧な記号を正規化
  ↓
レスポンスとして保存
```

### 5.2 問題作成フロー

```
問題作成者による設定
  ↓
プロパティフォーム
  ↓
PCI設定の更新
  ↓
ウィジェット再レンダリング
  ↓
QTI XMLへのシリアライズ
```

## 6. 外部インターフェース

### 6.1 IMS PCI 標準インターフェース

本PCIは、IMS Global Learning Consortium の PCI 仕様 v1.0 に準拠している。

**主要メソッド：**
- `getInstance(dom, config, state)` - インスタンスの生成
- `getResponse()` - 受験者の回答取得
- `getState()` / `setState(state)` - 状態の保存・復元
- `oncompleted()` - 破棄処理

### 6.2 TAO プラットフォーム連携

TAO Assessment Platform の以下のAPIと連携：

- `qtiCustomInteractionContext` - PCIレジストリ
- `taoQtiItem/qtiCreator/widgets` - Creator ウィジェットフレームワーク
- `taoQtiItem/portableLib` - 共通ライブラリ

## 7. 非機能要件

### 7.1 パフォーマンス

- 初期レンダリング：500ms以内
- ツールバーボタンのレスポンス：100ms以内
- 自動折り返し処理：リアルタイム（入力ごと）

### 7.2 互換性

- ブラウザ：Chrome, Firefox, Safari, Edge（最新2バージョン）
- QTI バージョン：QTI 2.1+
- TAO バージョン：3.x 以降

### 7.3 アクセシビリティ

- キーボード操作のサポート
- スクリーンリーダー対応（部分的）
- フォーカス管理

### 7.4 国際化

- 日本語ロケールでの特別な動作（分母へのフォーカス、特殊記号のラベル変更）
- 多言語プロンプトのサポート

## 8. セキュリティ考慮事項

### 8.1 入力検証

- LaTeX インジェクション対策：MathQuillによるサニタイゼーション
- XSS対策：HTMLエスケープ処理

### 8.2 データ保護

- 受験者の回答は暗号化せずに保存（TAOプラットフォーム側で実施）
- セッションデータの適切なクリーンアップ

## 9. 制約事項

### 9.1 技術的制約

- MathQuillライブラリに依存しているため、LaTeX以外の形式は非サポート
- MathMLはmathml-to-latexライブラリ経由で変換される
- インタラクティブモード（`-i`フラグ）のgitコマンドは使用不可

### 9.2 機能的制約

- Gap Expressionモードと通常モードの同時使用は不可
- 新しい行の挿入は実験的機能（`allowNewLine`オプション）
- 自動折り返しは実験的機能（`enableAutoWrap`オプション）
