## 1. IMS PCI 標準インターフェース

### 1.1 概要

本PCIは、IMS Global Learning Consortium の Portable Custom Interaction 仕様 v1.0 に準拠している。

### 1.2 getInstance メソッド

**シグネチャ：**
```javascript
getInstance(dom, config, state) : PCIInstance
```

**パラメータ：**

| パラメータ | 型 | 説明 |
|-----------|---|------|
| `dom` | DOMElement | PCIコンテナのDOM要素 |
| `config` | Object | 設定オブジェクト |
| `config.properties` | Object | PCIプロパティ |
| `config.onready` | Function | 初期化完了コールバック |
| `config.boundTo` | Object | バインドされたレスポンス |
| `state` | Object | 保存された状態（オプション） |

**戻り値：** なし（`config.onready(pciInstance)` で返却）

### 1.3 PCIInstance インターフェース

#### 1.3.1 getResponse()

**目的：** 受験者の回答を取得

**シグネチャ：**
```javascript
getResponse() : Response
```

**戻り値：**
```javascript
{
    base: {
        string: "x^2+1"  // LaTeX文字列（Gapモードではカンマ区切り）
    }
}
```

**Gap Expressionモード例：**
```javascript
{
    base: {
        string: "x^2,2x+1,5"  // 3つのGapの値
    }
}
```

#### 1.3.2 getState()

**目的：** 現在の状態をシリアライズ

**シグネチャ：**
```javascript
getState() : State
```

**戻り値：**
```javascript
{
    response: {
        base: {
            string: "x^2+1"
        }
    }
}
```

#### 1.3.3 oncompleted()

**目的：** PCIの破棄とクリーンアップ

**シグネチャ：**
```javascript
oncompleted() : void
```

**処理内容：**
- イベントリスナーの削除
- `mathEntryInteraction.destroy()` の呼び出し

## 2. PCI カスタムイベント

### 2.1 イベントシステム

PCIインスタンスは、イベントマネージャを使用してカスタムイベントを発火・購読する。

**イベントマネージャの追加：**
```javascript
event.addEventMgr(pciInstance);
```

### 2.2 イベント一覧

#### 2.2.1 configChange

**方向：** Creator → Runtime

**発火：** `interaction.triggerPci('configChange', [properties])`

**購読：** `pciInstance.on('configChange', function(properties) { ... })`

**パラメータ：**
- `properties` (Object): 更新されたプロパティオブジェクト

**用途：** プロパティ変更時のUIの再レンダリング

**例：**
```javascript
pciInstance.on('configChange', function (properties) {
    mathEntryInteraction.render(properties);
    mathEntryInteraction.postRender();
});
```

#### 2.2.2 responseChange

**方向：** Runtime → Creator

**発火：** `pciInstance.trigger('responseChange', [latex, index])`

**購読：** `interaction.onPci('responseChange', function(latex, index) { ... })`

**パラメータ：**
- `latex` (String): LaTeX文字列
- `index` (String, optional): 入力フィールドのインデックス

**用途：** 受験者の回答変更を通知

**例：**
```javascript
interaction.onPci('responseChange', function (latex, index) {
    if (interaction.prop('useGapExpression')) {
        interaction.prop('gapExpression', latex);
    }
});
```

#### 2.2.3 addGap

**方向：** Creator → Runtime

**発火：** `interaction.triggerPci('addGap')`

**購読：** `pciInstance.on('addGap', function() { ... })`

**パラメータ：** なし

**用途：** Gapの追加

**例：**
```javascript
pciInstance.on('addGap', function () {
    mathEntryInteraction.addGap();
});
```

#### 2.2.4 addAlternative

**方向：** Creator → Runtime

**発火：** `interaction.triggerPci('addAlternative', [latex, gapValues, responseId])`

**購読：** `pciInstance.on('addAlternative', function(latex, gapValues, responseId) { ... })`

**パラメータ：**
- `latex` (String): LaTeX式
- `gapValues` (Object): Gap値オブジェクト
- `responseId` (String): レスポンスID

**用途：** 代替回答の追加

**gapValues構造：**
```javascript
{
    base: {
        string: "gap1,gap2,gap3"  // または配列
    }
}
```

#### 2.2.5 latexInput

**方向：** Creator → Runtime

**発火：** `interaction.triggerPci('latexInput', [latex, index])`

**購読：** `pciInstance.on('latexInput', function(latex, indexInput) { ... })`

**パラメータ：**
- `latex` (String): LaTeX文字列
- `indexInput` (String): 入力フィールドのインデックス

**用途：** 通常モードでのLaTeX入力設定

**例：**
```javascript
pciInstance.on('latexInput', function (latex, indexInput) {
    if (!mathEntryInteraction.inputs.has(indexInput)) {
        return false;
    }
    mathEntryInteraction.mathField = MQ.MathField(
        mathEntryInteraction.inputs.get(indexInput).input,
        config
    );
    mathEntryInteraction.setLatex(latex, indexInput);
    mathEntryInteraction.mathField.focus();
});
```

#### 2.2.6 latexGapInput

**方向：** Creator → Runtime

**発火：** `interaction.triggerPci('latexGapInput', [gapLatex, index])`

**購読：** `pciInstance.on('latexGapInput', function(gapLatex, indexInput) { ... })`

**パラメータ：**
- `gapLatex` (Object): Gap LaTeXオブジェクト
- `indexInput` (String): 入力フィールドのインデックス

**用途：** Gap Expressionモードでの入力設定

**gapLatex構造：**
```javascript
{
    base: {
        string: ["x^2", "2x+1", "5"]  // 配列形式
    }
}
```

#### 2.2.7 deleteInput

**方向：** Runtime → Creator

**発火：** `pciInstance.trigger('deleteInput', [dataIndex])`

**購読：** `interaction.onPci('deleteInput', function(inputId) { ... })`

**パラメータ：**
- `inputId` (String): 削除する入力フィールドのID

**用途：** 入力フィールドの削除通知

## 3. PCI 設定プロパティ

### 3.1 基本プロパティ

| プロパティ | 型 | デフォルト | 説明 |
|-----------|---|-----------|------|
| `responseIdentifier` | String | - | レスポンス識別子 |
| `authorizeWhiteSpace` | Boolean | false | スペースキー入力を許可 |
| `useGapExpression` | Boolean | false | Gap Expressionモードを有効化 |
| `gapExpression` | String | '' | Gap式のLaTeX |
| `gapStyle` | String | - | Gapサイズ（'math-gap-small', 'math-gap-medium', 'math-gap-large'） |
| `focusOnDenominator` | Boolean | false | 分数入力時に分母へフォーカス（日本語では自動でtrue） |
| `inResponseState` | Boolean | false | 正解入力状態フラグ（Creator内部用） |
| `isReviewMode` | Boolean | false | レビューモードフラグ |
| `allowNewLine` | Boolean | false | 改行を許可（実験的機能） |
| `enableAutoWrap` | Boolean | false | 自動折り返しを有効化（実験的機能） |

### 3.2 ツールバープロパティ

全てのツールについて `tool_{toolId}` 形式のBoolean型プロパティが存在する。

**関数系：**
- `tool_frac` (分数)
- `tool_sqrt` (平方根)
- `tool_exp` (指数)
- `tool_log` (対数)
- `tool_ln` (自然対数)
- `tool_limit` (極限)
- `tool_sum` (総和)
- `tool_nthroot` (n乗根)
- `tool_subscript` (下付き文字)

**記号系：**
- `tool_e` (ネイピア数)
- `tool_infinity` (無限大)
- `tool_pi` (円周率)
- `tool_lbrack`, `tool_rbrack` (角括弧)
- `tool_lparen`, `tool_rparen` (丸括弧)
- `tool_lbrace`, `tool_rbrace` (波括弧)
- `tool_colon` (コロン)
- `tool_to` (矢印)
- `tool_degree` (度記号)
- `tool_percent` (パーセント)

**幾何系：**
- `tool_angle` (角)
- `tool_triangle` (三角形)
- `tool_similar` (相似)
- `tool_paral` (平行)
- `tool_perp` (垂直)
- `tool_vline` (縦線)

**三角関数系：**
- `tool_sin` (サイン)
- `tool_cos` (コサイン)
- `tool_tan` (タンジェント)

**比較演算子系：**
- `tool_lower` (<)
- `tool_greater` (>)
- `tool_lte` (≤)
- `tool_gte` (≥)
- `tool_approx` (≈)

**演算子系：**
- `tool_equal` (=)
- `tool_plus` (+)
- `tool_minus` (-)
- `tool_times` (×)
- `tool_timesdot` (·)
- `tool_divide` (÷)
- `tool_plusminus` (±)

**集合系：**
- `tool_inmem` (∈)
- `tool_ninmem` (∉)
- `tool_union` (∪)
- `tool_intersec` (∩)
- `tool_congruent` (≅)
- `tool_subset` (⊂)
- `tool_superset` (⊃)
- `tool_contains` (∋)

**積分系：**
- `tool_integral` (∫)

**行列系：**
- `tool_matrix_2row` (2行行列)
- `tool_matrix_2row_2col` (2行2列行列)

## 4. TAO Creator インターフェース

### 4.1 Interaction API

#### 4.1.1 prop(name, value)

**目的：** プロパティの取得/設定

**シグネチャ：**
```javascript
// 取得
prop(name: string) : any

// 設定
prop(name: string, value: any) : void
```

**例：**
```javascript
// 取得
var useGap = interaction.prop('useGapExpression');

// 設定
interaction.prop('useGapExpression', true);
```

#### 4.1.2 attr(name, value)

**目的：** 属性の取得/設定

**シグネチャ：**
```javascript
// 取得
attr(name: string) : any

// 設定
attr(name: string, value: any) : void
```

**例：**
```javascript
var id = interaction.attr('responseIdentifier');
interaction.attr('responseIdentifier', 'RESPONSE_1');
```

#### 4.1.3 getResponseDeclaration()

**目的：** レスポンス宣言オブジェクトを取得

**シグネチャ：**
```javascript
getResponseDeclaration() : ResponseDeclaration
```

**戻り値：** ResponseDeclaration オブジェクト

#### 4.1.4 triggerPci(eventName, args)

**目的：** PCIイベントを発火

**シグネチャ：**
```javascript
triggerPci(eventName: string, args: Array) : void
```

**例：**
```javascript
interaction.triggerPci('configChange', [interaction.getProperties()]);
```

#### 4.1.5 onPci(eventName, handler)

**目的：** PCIイベントを購読

**シグネチャ：**
```javascript
onPci(eventName: string, handler: Function) : void
```

**例：**
```javascript
interaction.onPci('responseChange', function(latex) {
    console.log('Response changed:', latex);
});
```

#### 4.1.6 offPci(eventName)

**目的：** PCIイベントリスナーを削除

**シグネチャ：**
```javascript
offPci(eventName: string) : void
```

### 4.2 ResponseDeclaration API

#### 4.2.1 setTemplate(template)

**目的：** レスポンステンプレートを設定

**シグネチャ：**
```javascript
setTemplate(template: string) : void
```

**パラメータ：**
- `template` (String): テンプレート名（'MAP_RESPONSE', 'MATCH_CORRECT', etc.）

#### 4.2.2 getMapEntries()

**目的：** マッピングエントリを取得

**シグネチャ：**

getMapEntries() : Object

#### 4.2.3 setMapEntry(key, value, fireEvent)

**目的：** マッピングエントリを設定

```javascript
setMapEntry(key: string, value: number, fireEvent: boolean) : void

**パラメータ：**
- `key` (String): 回答文字列
- `value` (Number): スコア値

#### 4.2.4 removeMapEntry(key, fireEvent)

**目的：** マッピングエントリを削除

removeMapEntry(key: string, fireEvent: boolean) : void

**目的：** 全マッピングエントリを削除

**シグネチャ：**

```

#### 4.2.6 getMappingAttribute(name)

**目的：** マッピング属性を取得

**シグネチャ：**
```javascript
getMappingAttribute(name: string) : any
```

**属性名：**
- `defaultValue`: デフォルトスコア

- `upperBound`: スコアの上限

#### 4.2.7 setCorrect(value)

**目的：** 正解を設定

**シグネチャ：**
```javascript
setCorrect(value: string) : void
```

#### 4.2.8 getCorrect()

**目的：** 正解を取得

**シグネチャ：**
```javascript
getCorrect() : Array<string>
```

**戻り値：** 正解文字列の配列

## 5. MathQuill API

### 5.1 MathField API

#### 5.1.1 MQ.MathField(element, config)

**目的：** 編集可能な数式フィールドを作成

**シグネチャ：**
```javascript
MQ.MathField(element: DOMElement, config: Object) : MathField
```

**configオプション：**
- `spaceBehavesLikeTab` (Boolean): スペースキーの動作
- `focusOnDenominator` (Boolean): 分母へのフォーカス
- `handlers` (Object): イベントハンドラ
  - `edit(mathField)`: 編集時
  - `enter(mathField)`: Enterキー押下時

#### 5.1.2 mathField.latex(latex)

**目的：** LaTeXの取得/設定

**シグネチャ：**
```javascript
// 取得
latex() : string

// 設定
latex(latex: string) : void
```

#### 5.1.3 mathField.write(latex)

**目的：** カーソル位置にLaTeXを書き込み

**シグネチャ：**
```javascript
write(latex: string) : void
```

**動作：** カーソルの右側に挿入、カーソルは右に移動

#### 5.1.4 mathField.cmd(latex)

**目的：** LaTeXコマンドを実行

**シグネチャ：**
```javascript
cmd(latex: string) : void
```

**動作：** コマンドを挿入、カーソルはコマンド内部に移動

#### 5.1.5 mathField.focus()

**目的：** フィールドにフォーカス

**シグネチャ：**
```javascript
focus() : void
```

#### 5.1.6 mathField.revert()

**目的：** MathQuillフィールドを元のHTML要素に戻す

**シグネチャ：**
```javascript
revert() : void
```

### 5.2 StaticMath API

#### 5.2.1 MQ.StaticMath(element)

**目的：** 静的な数式フィールドを作成

**シグネチャ：**
```javascript
MQ.StaticMath(element: DOMElement) : StaticMath
```

**特徴：** `\\MathQuillMathField{}` をGapとして認識

#### 5.2.2 staticMath.innerFields

**目的：** Gapフィールドの配列

**型：** `Array<MathField>`

**例：**
```javascript
var gaps = staticMath.innerFields;
gaps.forEach(function(gap) {
    gap.latex('x^2');
});
```

### 5.3 Custom Embed API

#### 5.3.1 MQ.registerEmbed(name, factory)

**目的：** カスタムEmbed要素を登録

**シグネチャ：**
```javascript
MQ.registerEmbed(name: string, factory: Function) : void
```

**factoryの戻り値：**
```javascript
{
    htmlString: string,  // HTML文字列
    text: function() : string,  // テキスト表現
    latex: function() : string  // LaTeX表現
}
```

**例：**
```javascript
MQ.registerEmbed('gap', function() {
    return {
        htmlString: '<span class="mq-tao-gap"></span>',
        text: function() { return 'tao_gap'; },
        latex: function() { return '\\taoGap'; }
    };
});
```

## 6. データ形式

### 6.1 レスポンス形式

#### 6.1.1 通常モード

```javascript
{
    base: {
        string: "x^2+2x+1"
    }
}
```

#### 6.1.2 Gap Expressionモード

```javascript
{
    base: {
        string: "x^2,2x,1"  // カンマ区切り
    }
}
```

### 6.2 設定オブジェクト形式

```javascript
{
    properties: {
        authorizeWhiteSpace: false,
        useGapExpression: true,
        gapExpression: "\\frac{\\taoGap}{\\taoGap}=\\taoGap",
        gapStyle: "math-gap-medium",
        tool_frac: true,
        tool_sqrt: true,
        // ... 他のツール設定
    },
    boundTo: {
        RESPONSE_1: {
            base: {
                string: "x^2,2x,1"
            }
        }
    },
    onready: function(pciInstance) {
        // 初期化完了コールバック
    }
}
```

### 6.3 状態オブジェクト形式

```javascript
{
    response: {
        base: {
            string: "x^2+2x+1"
        }
    }
}
```
